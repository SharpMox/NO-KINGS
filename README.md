# NO-KINGS

A filterable codex of **38 fairy-chess pieces** — movement diagrams, Betza notation, fantasy
renames, and the relations between them (promotions, fusions, inversions).

**▶ Live site: https://sharpmox.github.io/NO-KINGS/**

Static HTML + vanilla JS; each catalog's data lives in a `data/*.js` file and mirrors the
"No Kings" game-design Notion databases.
