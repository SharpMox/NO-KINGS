Betza notation

Ralph Betza's letter notation, used on every card in this site.

Active

    Atomic leapers

    One-shot jumps to a fixed offset; intervening pieces ignored.

    LetterDiagramNameOffset
    WWazir(1,0)
    FFerz(1,1)
    DDabbaba(2,0)
    AAlfil(2,2)
    NKnight(1,2)
    C (or L)Camel(1,3)
    ZZebra(2,3)
    HThreeleaper(3,0)
    GTripper(3,3)

    Non-standard leapers use an explicit offset, e.g. (1,4) Giraffe.

    Sliders & standard compound atomics

    LetterDiagramNameEquivalent to
    KKingW + F — one square in any of 8 directions
    RRookW-rider — slides any distance orthogonally
    BBishopF-rider — slides any distance diagonally
    QQueenR + B — slides 8 directions

    Riders (doubled letter = repeat the leap)

    Doubled letter repeats the leap in a straight line until blocked at a landing square.

    NotationDiagramNameMovement
    NNNightriderAny number of Knight leaps in a single line
    CCCamelriderAny number of Camel leaps in a single line
    AAAlfilriderAny number of Alfil leaps in a single line
    DDDabbabariderAny number of Dabbaba leaps in a single line

    Direction prefixes (lowercase)

    Restrict the next uppercase move to specific directions.

    PrefixMeaningExample
    fForward onlyfR = Lance (forward Rook)
    bBackward onlybR = backward Rook (used in Eagle)
    lLeft onlylW = left Wazir
    rRight onlyrW = right Wazir
    sSideways (left + right)sW = sideways Wazir
    vVertical (forward + backward)vR = vertical Rook

    Prefixes combine, e.g. fs = forward + sideways.

    Power modifiers

    PrefixMeaningExample
    mMove only (no capture)mfW = Pawn's straight forward move
    cCapture only (no quiet move)cfF = Pawn's diagonal capture
    eEn passant variantcefF = capture forward Ferz including en passant
    iInitial move only (first move)imfnD = Pawn's two-square first move
    nNon-jumping (can be blocked at intermediate squares)nN = Mao (Xiangqi Horse — blockable Knight)
    jJumping (ignores intermediate squares — usually implicit)Most leapers are already jumping

    Hop & bend prefixes

    PrefixMeaningExample
    pPao-style hop: capture by jumping over one piece on a linecpR = Cannon's hop-capture along Rook lines
    gGrasshopper hop: must jump over one piece, land immediately past itgQ = Grasshopper, gB = Bishopper
    zZigzag bend: turns 90° after each stepzB = Boyscout (crooked Bishop)
    tBent rider: one step in the first piece's style, then continues outward in the second's stylet[FR] = Gryphon, t[WB] = Manticore

    Numbers and brackets

    SyntaxMeaningExample
    XnLimit a slider to n squares maximumQ2 = Bodyguard (Queen capped at 2 squares)
    (m,n)Explicit leaper offset for non-standard leapers(1,4) = Giraffe
    [XYZ]Grouping for the bent-rider t prefixt[FR] reads "Ferz step then outward Rook"
